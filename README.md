What was the problem you were solving in the projects for this course?
In these projects we were tasked with creating a program that can take information from a csv and pass it into a datastructure
Throughout the process we explored a variety of options, including a vector, a hash table, and a binary tree. In the end it was decided that the best course of action would be to store all the information in a hash table, which is what you see in the final project

How did you approach the problem? Consider why data structures are important to understand.
Approaching this issue one step at a a time, and exploring the various manipulation methods available when dealing with different data structures. Each of the various data structures had similar core elements, we would break input into line by line input and then parse that data into the various objects they belonged too. 

How did you overcome any roadblocks you encountered while going through the activities or project?
When I hit any road blocks I found myself using the rubber duck method, where I would explain what was happening in the program to something or someone outside of myself. This helped me move through some pretty weird bugs. 

How has your work on this project expanded your approach to designing software and developing programs?
This project helped me understand how to store and manage data in a way I just didn't before. After this class, and project I've found that I have a far easier time holding on to data in my programs.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
I am a bit better at writing programs that can be moved around more. I tested myself half way through this project and ripped up what I wrote and put it into a seperate file. All the functions that were moved functioned normally and everything went without a hitch.
